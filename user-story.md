# User Story Template

## Title
Manage Account Records Through the REST API

## User Story
As an application user,  
I need the ability to create, read, update, delete, and list account records,  
So that I can manage account information efficiently.

## Acceptance Criteria
- Given the Account REST API is running
- When I submit valid account information
- Then a new account is created

- Given an account exists
- When I request its details by ID
- Then the account information is returned

- Given an account exists
- When I submit valid updated information
- Then the account is updated

- Given an account exists
- When I request its deletion
- Then the account is deleted

- Given multiple accounts exist
- When I request the account list
- Then the API returns the available accounts
