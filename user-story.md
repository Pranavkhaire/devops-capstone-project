# User Story: Manage Accounts

## Title
Manage Account Records Through the REST API

## User Story
As an application user,  
I need the ability to create, read, update, delete, and list account records,  
So that I can manage account information efficiently.

## Acceptance Criteria
- **Given** the Account REST API is running, **when** I submit valid account information, **then** a new account is created.
- **Given** an account exists, **when** I request its details using its ID, **then** the account details are returned.
- **Given** an account exists, **when** I submit valid updated information, **then** the account is updated.
- **Given** an account exists, **when** I request its deletion, **then** the account is deleted.
- **Given** multiple accounts exist, **when** I request the account list, **then** the API returns the available accounts.
